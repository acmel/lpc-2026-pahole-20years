DWARF is a moving target


  • Compilers: gcc, clang, rustc...
  • Versions, vendors, distro packaging
  • Standards evolve: DWARF 2..5, 6 coming
  • Same source, different DWARF

Case 1: missing .bss DATASEC


  • Failures on AlmaLinux 8 containers
  • bpftool v4.18.0: no .bss DATASEC in dumps
  • bpftool v7.5+: correct
  • Not a pahole bug: old tool can't display it

  if echo "$dump" | grep -q "DATASEC '\.bss'"; then
      check_bss_variable
  else
      info_log "skip: bpftool doesn't display .bss DATASEC"
  fi

Case 2: _Atomic typedefs



  typedef _Atomic int atomic_int;
  struct test { atomic_int x; };
  • clang 21.1.8: typedef → base_type (no atomic node)
  • gcc/clang 22+: typedef → DW_TAG_atomic_type
  • pahole reads DWARF, not source: both outputs correct

Proving it: artifact dumps



  === DWARF atomic types (abbreviated) ===
  (empty)                        # No DW_TAG_atomic_type!
  === pahole --compile output ===
  typedef int atomic_int;        # correct, per the DWARF
  • Capture before the container exits
  • Input (DWARF) vs output (pahole), side by side
  • tests/tests -v --dump-artifacts 51

Case 3: DWARF versions


  • Default DWARF version varies by distro
  • Features only in newer versions (_Atomic needs 5)
  • Force it when testing features:

  gcc -gdwarf-5 -c test.c

Case 4: BTF VAR support


  • Old bpftool: no VAR entries in output
  • Skip when the tool is too old, say why

  if ! echo "$dump" | grep -q '\[.*\] VAR'; then
      info_log "skip: bpftool doesn't support VAR in dump output"
      test_skip
  fi

Testing philosophy


  • Pass or gracefully skip: RHEL8 to Fedora latest
  • Detect capabilities, don't assume them
  • Every skip explains: what, where, why not a bug

First non-C language: C++


  • Dec 2006, weeks after the Oct 24 start: DW_TAG_inheritance
  • Early users: developers at CERN, 32-bit to 64-bit move
  • Their codebase: mostly C++
  • Then: namespaces (2007), class_type (2008), templates

What's new: languages


  • C++ tags: namespaces, templates, using-decls
  • Rust: variant parts, discriminants (eBPF track talk!)
  • Non-C precedent: Go at Trace Summit Bilbao 2023

What's new: plumbing


  • DWZ alternate debug files
  • Partial units, split DWARF
  • Modern distro DWARF just works
  • Coverage analysis, growing regression suite

perf integration: finally real


  • Perennial request: pahole + perf together
  • Data-type profiling supplies access weights
  • pahole proposes cacheline groups, flags false sharing
  • Full story at Cauldron (yesterday?)

Lessons learned


  • Compilers are inconsistent: read the DWARF
  • Tools evolve at different rates (6 years of bpftool!)
  • Tests must be environment-aware
  • Dumps save hours of debugging

Future


  • Rust: niche layouts, const generics, async machines
  • DWARF 6: new tags, adoption varies
  • BTF extensions for what C can't express
